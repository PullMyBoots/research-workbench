# Notebook Archive

`./explore reflect` moves the previous root `notebook.md` into this directory
before writing the next four-chapter iteration notebook at the Route root.

Archived notebooks are the complete short-term trail for past iterations. The
active Auditor target and Builder/Debug logs remain in `../notebook.md`; durable
lessons belong to the corresponding Version reflection.

Reflection input files such as root-level `reflection.md` and `next_plan.md`
are temporary. After a successful `./explore reflect`, they should be archived
here by the CLI so the route root stays focused on the current control surface.
Older pre-cleanup root Markdown may live under `legacy-root-markdown/`.
